# STM32 直流电机驱动

这是一个电赛 B 题练习项目。目标是用四个独立按键控制直流电机的启动、停止、停机换向和三档调速。

## 我负责的部分

我负责驱动板的硬件设计和 PCB 修改。驱动电路由两片 IR2104 驱动 H 桥，两个半桥共用一根使能信号。板上增加了 5 V 降压模块和电源接口，设计上由 11.2 V 直流电源同时为驱动板和 STM32 开发板供电。

## 控制方案

固件以 STM32F103C8T6 为控制器。TIM3 输出约 20 kHz 的 PWM，三档占空比初值为 30%、50% 和 75%。上电默认停机，停止优先于其他按键，运行中屏蔽换向请求。换向时先停机，等电机轴停稳后再选方向并重新启动。

## 验证进度

- **PCB**：修改布线并重建铜皮后，设计规则检查（DRC）通过。
- **固件**：已完成编译，并在 Cortex-M3 指令模拟器中检查复位、启停、换向和三档切换。
- **实物**：ST-LINK 烧录、驱动波形和实际转速仍待上板验证。三档百分比是 PWM 占空比的设定值。
